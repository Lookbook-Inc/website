# Lookbook web applications

- `website/` — the existing marketing and Style Snapshot application.
- `edits-web/` — the separately deployed, read-only companion for production Lookbook members.

Each directory is an independent Vercel project with its own dependencies and environment variables. See [`edits-web/README.md`](edits-web/README.md) for the Edits deployment and rollout checklist.
